# Deep Learning for Computer Vision

Coursework from the *Deep Learning for Computer Vision* course at Yazd University
(Fall 2025), taught by Dr. Mohammad T Sadeghi. The course is inspired by
Stanford's CS231n. I finished it at the top of my class.

This repository contains three homework assignments and a final project,
all implemented in PyTorch. Notebooks include their outputs, so results are
visible without re-running.

## Contents

| Folder | Topic | Highlights |
|---|---|---|
| `01_mlp_cifar10` | Fully connected network on CIFAR-10 | Activation and batch-size study, overfitting, KNN baseline |
| `02_cnn_cifar10` | CNN on CIFAR-10 | Feature maps, BatchNorm, Dropout, 78.8% test accuracy |
| `03_semantic_segmentation` | Semantic segmentation on Pascal VOC | Fully convolutional encoder–decoder |
| `final_project` | Implementation of a research paper | Simplified version of my bachelor's thesis |
